wrAIter adds highlighter colors and a tunnel button directly to LibreOffice's toolbar. Double-click a color to edit its prompts and permissions; protection disables wording changes. Document suggestions require local approval unless its highlights explicitly permit direct edits. The tunnel window controls the independent MCP/zrok connection, document sharing and separate project-folder/GitHub access. Choose Read or Read + write for one folder and explicitly allow it. GitHub access separately permits named-file commits, fast-forward synchronization and new repository creation. Folder access never replaces Writer's highlighted-document permissions. Restart restores connection preferences, never document/folder/GitHub grants. Stop revokes access. No shell or remote save/policy control is exposed. UnderTree and Secret Tunnel are not required.
