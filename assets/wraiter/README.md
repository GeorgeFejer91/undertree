# wrAIter icon

`icon.svg` is the approved AI waiter/typewriter logo, shared by the LibreOffice
Writer and Microsoft Word add-ons. It is the same artwork as `../raider-v3.svg`.
The PNG exports are rendered directly from that SVG at their named pixel sizes;
`icon.ico` contains the 16, 24, 32, 48, 64, 128 and 256 px Windows frames.

LibreOffice packages its toolbar and Extension Manager PNGs. Word embeds its
ribbon PNG and window ICO in the DLL and ships the ICO for its installer and
Windows installed-app entry. Neither add-on needs the other at runtime.

`social-preview.png` is the 1280 × 640 repository/share image using this same
mark. It is prepared for GitHub's repository social-preview setting; its presence
in the checkout does not mean it has been uploaded there. README and package
selection links use the SVG directly. See [download instructions](../../docs/downloads.md)
and the [branding protocol](../../For-AI/PROTOCOLS/branding.md).
