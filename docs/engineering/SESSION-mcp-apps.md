Design: freeze only tool-referenced ui:// HTML resources at local link with 512 KiB per HTML, 32 resources overall, existing 2 MiB aggregate catalogue bound and HTTP bounds. Resource/tool change notifications invalidate the app. Preserve resource `_meta.ui` CSP and tool metadata, rewrite declared resource identities. Only declared app-only mcp_chat_decide/receipt aliases and the widget's existing UI handshake/context methods pass; each page request ID obtains one bounded stable UUID envelope. Unknown calls fail locally and arguments/tokens are never logged. Upstream retains approval authority. Other resource HTML is not claimed interactive-compatible without its own adapter.

UI resources may be omitted from resources/list; resources/read content metadata owns CSP; app-only visibility is preserved for host enforcement. This gateway does not invent a new UI permission or claim the bearer transport proves human identity.
