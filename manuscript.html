Open a local project from File. Typst and HTML sources and their adjacent review files stay in that folder.

Use Ctrl/⌘ S to save and Ctrl/⌘ Enter or F5 to compile Typst. Source formatting changes your selected text and remains undoable.

Format → Highlight selection attaches a color rule or prompt. ChatGPT proposals appear in Review; only your local decisions change the source.

File → Import to Typst converts a TeX source into a new file and report. Unsupported formatting is reported and the original is retained.
