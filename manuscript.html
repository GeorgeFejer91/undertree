UnderTree help

Open a local project from File. Typst, LaTeX and HTML sources and their adjacent review files stay in that folder.

Use Ctrl/⌘ S to save and Ctrl/⌘ Enter or F5 to compile Typst or LaTeX. Source formatting is available for Typst and HTML and remains undoable.

Insert adds math, citations, cross-references, links, figures and tables in Typst source. Replace selected placeholders with your bibliography keys, labels or image paths. Every insertion is undoable.

Format → Highlight selection attaches a color rule or prompt. ChatGPT proposals appear in Review; only your local decisions change the source.

File → Import to Typst optionally converts a TeX source into a new file and report. Conversion is not required to compile LaTeX. Unsupported formatting is reported and the original is retained.

What this counts

Literal prose is an estimate from this source. Typst literal content can count even in unused definitions; evaluated strings, raw code, math, comments and included files are excluded. HTML counts decoded body text, including hidden ordinary text, but excludes scripts, styles, templates, code, preformatted text, textarea, math and SVG. Attributes and image alternatives are not counted.

Source and source-selection counts include markup. Each nonempty selected range is counted independently. All counts use the displayed Unicode word-segmentation locale; numbers count as words, while punctuation and emoji alone do not.
